# 逐轮实验记录

每轮创建 `<date>-<topic>/`，保存 `README.md` 和 `record.json`。大照片与原始反馈仍在 feedback/ 中，通过试绣 ID 和路径关联，不重复复制 DST 或发布图像。

[templates/record.json](templates/record.json) 记录问题、假设、改动、固定条件、证据、结果与接受/回退决定。生成器版本、订单候选版本和样本库版本分别记录。

[2026-10-13-reference-guided-v002/](2026-10-13-reference-guided-v002/README.md) 是从已有配置、报告及 Git 记录补录的 v002 实验，不虚构实机结果。后续创建候选时先写假设，结果出来再追加判定。
