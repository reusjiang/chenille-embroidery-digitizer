我们的任务目标：

建立一套 雪尼尔刺绣自动打带系统。系统读取订单 PDF 后，自动完成：

1. 识别文字内容、大小写、Font1／Font2／Font3、分行及排版。
2. 根据对应的原始字体曲线和历史人工 DST 笔顺制作走线。
3. 学习并保留人工打带中的连笔、回走、交叉顺序、转弯缩针、起收针和必要空移。
5. 自动生成大豪 A15‑PLUS 可读取的 DST 文件，并输出尺寸、针数、空移、预览和逐针回放。
6. 对 DST 进行双重回读、文件头、结束指令、针长和尺寸检查。
7. 根据实机试绣结果持续修正，最终实现：

> 上传订单 PDF → 自动识别字体与文字 → 自动生成流畅、符合人工打带习惯、可直接上机使用的雪尼尔 DST 文件。
