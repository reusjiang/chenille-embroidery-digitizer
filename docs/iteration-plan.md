# 雪尼尔 DST 实机反馈迭代方案

状态：建议方案，尚无实机结果；以下次数和通过条件是试验设计建议，不是设备厂家规定。

目标：将当前 Bulldogs 同词样本原型逐步变为可复现、可定位、可回退的生成系统。每一轮回答：哪一段出了什么问题、在什么工艺条件下出现、改了什么、是否改善、有没有损害别处。

## 当前路线更新：优先复用 DST 样本库

项目所有者已确认 `dst-library` 文件可以直接作为输出范例。完整路线见 [以 DST 样本库驱动的订单生成](library-driven-roadmap.md)。优先实现“订单匹配已有完整样本并原字节输出”，再实现同款变体及字母、数字、连接组合；缺失覆盖通过后续样本与反馈补齐。

当前盘点为 2,597 个 DST、2,596 份不同字节内容。整词复用和新词生成分别评价，不把同词参考重建当作新词能力。每轮除保存 DST 外，还保存样本索引、连接规则和工艺配置的版本与验证依据。

本文第 2 节保留为 v001 基线实验设计，不是当前操作入口；当前三款试绣使用 [v002 方案](../releases/reference-guided/v002/README.md)。后续开发优先级以本次样本库路线为准，以下实验记录与验证原则继续适用。

## 1. 建立三个互相独立的评价层

| 层级 | 检查内容 | 判断依据 |
|---|---|---|
| 文件与几何 | 文本、字体、字形比例、分行、落针宽度、笔顺、回线弧长、短针、跳转、文件完整性 | 原始字体/订单、路径模型、最终 DST 双重回读 |
| 实机运行 | 是否顺利读取、实际执行版本、断线/停机/重启、故障位置、完成用时 | 操作记录、控制器显示、视频；无法确认的针号允许记为范围 |
| 实物外观 | 圆环形状、毛线覆盖、回走双线、交叉堆线、起收头、面料起皱、字间距 | 带比例尺的照片、实物尺寸、人工合格样对照 |

文件合格不代表试绣合格。毛线外缘宽度也不等于 README 定义的落针路径宽度。实物尺寸同时记录在绷状态和按固定等待时间放松后的状态；不能把两种状态混为同一组。

若人工合格样与生成样都出现相同问题，先检查共同工艺条件；若只有某版本、某笔段重复出现，优先定位路径/落针。两者均只是排查方向，不单凭一次现象判定因果。

## 2. 首轮：固定 Bulldogs 基线

冻结本次输出作为 `BULL-F2-330-v001`：330.0 × 99.0 mm、786 条落针、零跳针；起/收回线 9.997757 / 9.981385 mm。不要覆盖该版本。

保存订单页、样本路径与校验值、Font2 文件校验值、生成脚本版本、完整参数、DST 校验值、解码 CSV、预览和验证结果。针数或针距变化时创建新版本，不沿用旧照片。

首轮建议：

1. Wilcom 打开该 DST，核对尺寸、镜像/旋转、主路径及起收两端。若另存文件或在机器上缩放、旋转、调针迹，记录实际使用的文件/变换，不能把结果归因于原文件。
2. 使用常用的一套面料、衬料、毛线、针具、绷框和现行机器设置，先不同时调整工艺参数。记录实际设备、控制器、机头/装置及工作模式；不能仅靠“A15-PLUS”名称推断全部机械配置。
3. 当前版本先重复两次，判断重复性；差异大时补第三次，并排查装框、张力等条件。断线、停机或明显异常时记录原因，不要求为了完成重复次数继续运行。
4. 有该工艺下已确认合格的人工 Bulldogs 时增加对照。库内 `fon2/Bulldogs.DST` 只能先算候选对照，不能因其是人工样本就默认已经试绣合格。该样本原宽约 328.9 mm，与新版本 330.0 mm 有差异；用于局部外观比较时注明差异，若要同尺寸对照，必须独立记录调整方式，不能默默拉伸。

首轮固定观察点：

| 位置 | 当前已知状态 | 要记录的问题 |
|---|---|---|
| 起针第 1–10 针 | 圆弧回线，设计半径 0.35 mm | 是否起头不牢、堆毛线、掉头生硬 |
| 收针第 778–786 针 | 圆弧回线，设计半径 0.25 mm | 是否露尾、局部堆积、回退过于明显 |
| 两端圆弧 | 合计 7 个小于 0.5 mm 的非零针距，最短 0.2 mm | 短针是否与停机/堆线在空间位置上对应；不能预先认定是根因 |
| 内部折返 | 原样本第 34、63、120、186、225、414、581、613、656 针附近 | 哪些尖转应保留字形，哪些需要局部改圆 |
| B、双 l、d/g 回走和交叉 | 保留人工笔顺 | 是否出现双线、鼓包、形状偏离 |

注意：原样本针号与新生成针号不同。后续重采样也会改变针号，因此长期记录必须同时保存稳定笔段标识。

## 3. 每次试绣的最小反馈包

使用 `feedback/templates/trial-record.json` 复制为每次试绣的独立记录。不知道的数据填 null，不能猜。

必需信息：版本 ID、实际 DST 校验值、日期、面料/衬料/毛线标识、机器与装置、设置记录、绷框及装框方式、是否做软件或机器端变换、成功/失败、停机断线次数、问题位置、整体评价。

照片建议：全图正面、问题局部近照、背面（有助于该问题时）；关键故障可配视频。拍摄尽量正对、均匀照明，在面料同一平面放尺，并标明方向。在绷与放松照片分开命名。除非待验证，否则保持相同拍摄和放松等待条件。

第一阶段允许在照片上圈出问题，并标注“g 下环左侧 / 收针处”；不要求操作员精确辨识每针。后续界面再将标注关联到 segment_id、针号范围和坐标。毛线遮挡处不能靠照片声称还原了真实落针中心。

机器端针号与 CSV 针号若存在零位移或命令计数口径差异，需要先建立映射，不直接认为数字相同。

## 4. 每轮只检验一个主要假设

一次建议比较基线 A 与一个候选 B；结果模糊再增加 C。先使用原尺寸局部试片筛选，再回到完整单词验证；局部试片必须保留进入、退出和相邻回走的上下文，不得缩小整个单词来替代原尺寸试验。

例如“收针处堆线”的一轮：

- 假设：局部圆弧针距/重复覆盖与堆线相关。
- 固定：字形、笔顺、总宽、10 mm 回线要求、面料、毛线、机器设置等。
- 改动：仅修改收针区域的一项策略，例如圆弧半径或落针分布；候选数值根据首轮结果与操作者可用工艺范围设定。
- 检查：若圆弧半径变化必然影响回线偏移、针数或局部包围盒，逐项列出这些关联变化，不能宣称只有一个数发生变化。
- 评价：相同条件重复试绣，对照堆线、露尾、断线和字形保持情况；没有改善就保留旧版本。

推荐排查順序由实测问题决定，初始优先级为：两端短针与起收效果 → 内部尖转/回走 → 曲线平顺与针距 → 交叉顺序 → 有跳转的独立段 → 双行/长词排版。

全局缩放、拉长某个字母、随意改笔顺不能成为修补所有问题的默认方法。330 mm 是当前固定规格；实物补偿若需要偏离该规格，应作为独立策略与新目标明确记录。

## 5. 把反馈变成有适用范围的规则

规则分层保存：

- 订单要求：文字/大小写/字体、宽度、排版、10 mm 回线等。
- 字体与笔段规则：Font2 的某类上环、Font1 的 h/k 短笔、特定连接的进出笔顺。
- 机器和材料配置：特定设备/装置、毛线、布料、衬料、尺寸范围的试绣结论。
- 单款例外：只在某个单词/连接处验证过的局部修正。

每条规则必须有：适用条件、改动原因、支持的试绣 ID、对照版本、状态、失效/回退条件。不把一次成功推广到全部字体、材料或大小。历史人工样本提供初始笔顺；试绣记录提供该条件下效果的证据。

建议规则状态：`proposed → tested → accepted`，发现反例可 `deprecated`。未验证的例外不能静默修改生产配置。

## 6. 当前生成器的改造顺序

| 优先级 | 改造项 | 完成标准 |
|---|---|---|
| P0 | 参数配置、版本清单、文件校验值 | 同一输入、代码版本和配置可复现相同 DST；旧输出不被覆盖 |
| P0 | 稳定 segment_id 及源/目标针号映射 | 起回、B 上环、字肚、l1/l2、d/g 回走、末回都有可追踪标识 |
| P0 | 局部参数覆盖与版本对比 | 改收针只作用于指定笔段；报告所有连带变化和未改区域位移 |
| P1 | 试绣反馈页 | 绑定版本、上传本地照片/圈选问题、记录机器设置与判定；先用 JSON 也可 |
| P1 | 自动试片与候选生成 | 根据一个假设生成少量命名明确、经过完整回读的候选，而非无约束批量试错 |
| P1 | 回归样本集及发布门槛 | 修改后检查旧合格案例，能回退到已接受配置 |
| P2 | 字母与连接规则抽取 | 从多个已审查样本提取笔顺；未见连接单独验证 |
| P2 | 订单 OCR、字体匹配与未知款生成 | 保留识别置信度和人工纠错；低置信度不直接进入生产 |

现有代码的端点范围、回线半径、针距等有案例专用或写死的值。应先把可调项与不可变要求分开，再扩展到其他订单。现阶段也没有实测数据支持训练一个可靠的自动评分模型。

## 7. 验证与发布门槛

机器可读性和文件几何仍作为每个版本的必检项：双重回读、最终 END、范围/终点/针数一致、实际宽度、弧长回线、短针分布、局部过度重复、跳针及跳前跳后处理。设备可用的针长/模式限制按实际装置确认，不能把 DST 编码极限当成最佳工艺范围。

建议分为：

- **文件验证通过**：结构与既定几何约束通过，仅可进入试绣。
- **待比较候选**：完成单次试绣，还不足以替换已接受版本。
- **条件内接受**：建议至少两次同条件完整试绣表现一致；关键问题得到改善，未引入新的明显缺陷，并由操作者确认。
- **扩大适用范围**：再覆盖不同单词、代表性大小和目标材料，并保留未参与调参的验证词。

外观可以采用 0=无可见问题、1=轻微且可接受、2=需修改、3=无法接受的分项缺陷等级；不同问题分别评分，不用单一总分掩盖断线或字形错误。对绝对尺寸/局部偏差的实物阈值，应由人工合格样和客户要求建立；首轮不凭空承诺 0.1 mm 级照片测量精度。

回归集逐步覆盖：单连续词、独立点/横杠、h/k 上环和短笔、多处回走交叉、大写分段、连字符、双行、不同尺寸。每种字体保留一些未参与规则调整的单词；只在 Bulldogs 上变好不能证明通用能力。

## 8. 每轮输出固定内容

记录保存到 `experiments/<date>-<topic>/`，使用 [实验模板](../experiments/templates/record.json)；订单候选绑定记录使用 [生成记录模板](../orders/templates/generation-record.json)。已有 v002 已完成补录，见 [实验记录](../experiments/2026-10-13-reference-guided-v002/README.md)。

一轮完成后保留：候选 DST 与参数；版本/局部差异图；自动验证；实机记录与照片；哪项改善/未改善；决定接受还是回退；下一轮唯一主要假设。失败记录同样保存。

第一轮现在就可开始：对当前 Bulldogs 完成 Wilcom 核对和同条件重复试绣，回传“版本 ID + 全图 + 问题近照 + 当前设置 + 故障/尺寸记录”。随后根据具体位置生成第一组对照候选。

方法参考：Ink/Stitch 官方的[试片生成说明](https://inkstitch.org/docs/edit/)采用参数变化试片来比较结果；其[工作流程](https://inkstitch.org/docs/workflow/)也将试绣列为文件生成后的独立环节。这里只借鉴试验组织方法，不把其普通刺绣参数直接当成当前雪尼尔装置的参数。
