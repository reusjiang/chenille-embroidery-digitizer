# v001 历史基线操作指南

本指南面向实际设备操作方。本指南仅适用于历史基线 **Bulldogs / Font2 / BULL-F2-330-v001** 的试绣版，尚无实机验收记录。

## 1. 领取并确认版本

完整下载或解压交付包。打开 [版本目录](../releases/bulldogs-font2-330/v001/README.md)，检查版本 ID 和文件名。

上机使用的文件是 `Bulldogs_F2_330mm.DST`。不要把 `examples/` 中的人工参考 DST 当成本次试生成文件。

可双击版本目录中的 `preview.png`、`details.png` 看整体和局部；双击 `replay.html` 用本地浏览器看逐针回放，支持播放、步进和起收放大。无需联网或安装 Python。

v001 文件 SHA256：

```text
fd76864135643559e075c8cc5ea224a67472f2c21b7873889c3506576461e092
```

如需核对，在 Windows PowerShell 切换到 DST 所在目录后执行：

```powershell
Get-FileHash .\Bulldogs_F2_330mm.DST -Algorithm SHA256
```

哈希不相同表示文件内容已变化，先记录实际版本并让开发方核对。

## 2. Wilcom 核对

在现用 Wilcom EmbroideryStudio e4.2 中打开文件，记录是否正常导入，以及显示的宽高、针数和图形方向。

本版解码结果：330.0 × 99.0 mm，786 条普通落针命令，0 跳针；其中包含一条起点零位移命令。不同软件的统计口径若有差异，保留截图，不自行忽略差异。

检查 B、双 l、d/g 环和起收回线是否完整。若另存、缩放、旋转或修改针迹，保留实际使用的文件并记录改动，不能仍把结果写成未修改 v001 的效果。

## 3. 首轮试绣

使用操作方现有适用的设备设置，不从本项目推断针具、张力、转速或装置参数。记录实际机器、控制器、机头/装置、工作模式，以及面料、衬料、毛线、针具和装框方式。

建议先做两次同条件完整试绣来观察重复性。出现异常时按现场操作规程处理并记录，不要求为了凑次数继续运行。

重点观察：

| 部位 | 观察内容 |
|---|---|
| 起针第 1–10 针 | 是否稳固、是否堆线、掉头是否生硬 |
| 收针第 778–786 针 | 是否露尾、松脱、回走明显或局部鼓包 |
| B、双 l、d/g 环及交叉 | 形状、尖转、双线、交叉堆线 |
| 两端局部短针 | 是否与故障位置对应；不要仅凭针短就认定根因 |

以上针号是交付 CSV 中的编号；机器显示编号可能采用不同口径。无法确认时写字母和位置并拍照即可。

## 4. 拍照和测量

至少拍全图正面和问题部位近照；必要时补背面及故障视频。尽量正对面料、均匀照明，比例尺与面料放在同一平面，圈出问题位置。照片中避免出现客户地址、面单或其他不相关资料。

在绷尺寸、放松后尺寸分开记录，并写放松等待时间。记录测量的是落针中心参考范围还是毛线外缘；README 中的 330 mm 指落针路径，不能直接与蓬松毛线外缘比较。

## 5. 回传反馈

复制 [trial-report.md](../feedback/templates/trial-report.md) 填写；愿意使用结构化数据时也可填写 [trial-record.json](../feedback/templates/trial-record.json)。未知项保留空白或 null，不要猜。

建议回传一个目录：

```text
BULL-F2-330-v001_YYYYMMDD_01/
├── trial-report.md
├── front-overall.jpg
├── start-closeup.jpg
├── end-closeup.jpg
└── problem-01.jpg
```

通过双方约定渠道回传目录或压缩包。能使用 Git 时，先由开发方整理到 `feedback/reviewed/<trial-id>/`；原始待整理资料放本地 `feedback/inbox/`。不要把反馈文件写进冻结交付目录。

每轮反馈需说明：完成/未完成、断线及停机次数、问题位置、照片、当前设置、是否认可这一版。尚未试绣的模板不是合格记录。

## 6. 收到下一版

确认新版本号及变更说明；保持约定条件不变，比较指定部位。上一版与失败样片仍要保留。只有操作方完成试绣并确认，开发方才能将适用条件内的结论记为接受；文件结构验证不能代替这一环节。
