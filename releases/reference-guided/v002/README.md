# CHENILLE-REF-v002 刺绣候选方案

日期：2026-10-13。状态：**文件验证通过，待 Wilcom 检查和实机试绣**。

本版依据 `path-comparison-50-20260930` 的数字针路反馈，提供 3 款人工参考笔顺重建候选。打开 [候选总览](index.html) 可查看回放、对照图及下载各款 DST。

## 本版改动

1. 从经 SHA256 绑定的同词人工 DST 提取主路径，恢复 B 回环、双 l 谷底及 o/u/g 连笔的参考结构，保留内部笔顺、回走与有意尖转。
2. 分段拟合曲线并重新采样。内部尖转锚点在最终 0.1 mm 量化坐标中逐个校验，记录原针号与新针号的对应范围。
3. 替换参考稿原起收段，增加圆弧掉头的 10 mm 回线。针对弯曲进入段扩大回线长度搜索范围，在最终 DST 坐标上校验 10 ±0.05 mm。
4. 按人工稿原宽度校准最终落针包围盒。主路采样上限设为 2.3 mm，最终实际针距上限校验为 2.5 mm，给量化留余量。
5. 增加可复现配置、3 组冻结输入、输入哈希保护、稳定笔段 ID、逐针回放、三方对照和独立试绣表。

这是一个同词人工参考重建方案。50 份旧候选所用的 `studio/` 源码仍缺失，本版没有修改那个字体中线生成器。本版也未扩展到任意新词、独立点/横画、跳前跳后处理、双行或原生 EMB 导出。

## 数字对照结果

用同一套最大 0.25 mm 路径采样和包围盒中心平移方法，重算旧候选与本版到人工参考的双向距离。表中为两个方向 P95 的较大值。

| 样本 | 旧候选 mm | 本版 mm |
|---|---:|---:|
| Bulldogs / Font2 | 4.919 | 0.173 |
| Bulldogs / Font3 | 5.572 | 0.163 |
| Cougars / Font3 | 9.120 | 0.122 |

**人工稿同时作为本版输入和对照，上述结果衡量重建贴合程度。它不能证明新词泛化、实际落针精度或试绣合格。** 本次重新采样与旧资料的采样细节不同，所以旧候选重算值可能与原反馈表略有差异；新旧比较只使用本表同方法结果。

这一轮同时改变了主路径来源、曲线拟合、采样和起收回线。将它记录为完整候选方案比较；若实机出现差异，下一轮再固定其他项、逐个调整参数，不能直接把改善归因于某一个参数。

## 操作方试绣步骤

1. 解压交付包，打开 `index.html`。每款目录都有自己的 DST、回放、坐标表和 `trial-record.json`，文件校验值见 `validation.json`。
2. 用 Wilcom EmbroideryStudio e4.2 核对尺寸、方向、起收短针、回走及设备工作模式。当前 DST 为连续平针路径，没有增加机型专属毛巾绣/链式绣切换指令，也没有对应原生 EMB。
3. 先用现行已确认的机器、针具、材料、装框和设置试绣。填写实际使用 DST 的 SHA256；若另存、缩放、旋转或镜像，记录新文件与变换。
4. 每款先做两次同条件重复。记录全图、局部和同平面比例尺；分别记录在绷/放松状态、断线及停机位置、起收牢固性和外观判定。异常时由操作方判断是否继续，不为凑次数强行运行。
5. 人工参考、旧候选、本版可组成对照。交付包的 `reference-inputs/` 保存前两者并明确命名；人工参考本身也没有实机合格证明。
6. 反馈复制为新的试绣 ID，与原文件分开保存。未知值保持 `null`，操作方接受之前保持候选状态。

本轮重点：Bulldogs/F2 的 B 中腰及双 l 谷底；Bulldogs/F3 的 B 回环及 l/d 连接；Cougars/F3 的 o/u 过渡和 g 回环。三款都要观察新起收回线及非零短针。

## 文件与复现

- 每款：DST、`validation.json`、`segments.json`、`stitches.csv`、`replay-data.json`、`replay.html`、两张对照图、独立试绣模板及说明。
- 批次：`config.json`、`summary.json`、`build-info.json`、`manifest.json`。清单冻结本目录文件，避免不同构建的反馈混用。
- 仓库源码：`scripts/build_feedback_candidate.py`；配置：`configs/feedback-v002.json`；输入：`examples/feedback-v002/`。

从仓库根目录运行，输出目录必须为全新的 `build/` 子目录：

```sh
python scripts/build_feedback_candidate.py --output build/feedback-v002-rebuild
python -m unittest discover -s tests -v
```

生成器记录实际 Python 和依赖版本；精确复现环境见同目录 `requirements-build.txt`。本目录是已冻结候选快照，生成器不会覆盖 `releases/`。
