# Bulldogs / Font2 首次试生成

本次完成本地订单核对后的试点案例 的 **Bulldogs**，仅这一款。该页截图明确写有 `Font Number 2`，效果图与 Font2（Loverine）及同词人工 DST 对照相符。订单共 14 页，包含 15 个设计项；其余 14 项没有生成。

这是“同词人工路径复用 → 平滑曲线重建 → 回线重做 → 自适应落针 → DST 双重回读”的可运行原型。尚未实现任意订单 PDF 自动识别、未见文字的字体中线提取、跨样本字母拼接或通用人工笔顺学习。PDF 字体、文字和样本选择由本次人工式视觉核对完成，代码中保留这一已确认案例。原始文件均未修改。

## 文件

- `Bulldogs_F2_330mm.DST`：试生成 DST。
- `preview.png`：最终 DST 解码后的实际针迹。

## 样本与实际采用的规则

主要参考 `examples/bulldogs-font2/source.DST`，并将三套字体的 Bulldogs 字形与订单对照。Font1 / Font3 的同词样本仅用于排除字体，不混入本次走线。

原样本 808 条落针、零跳针。其第 1–6 针先从笔画内部退向左侧端点，随后沿入口向 B 继续；原起针回走实测 **10.426702 mm**。末梢到回线结束（第 802–806 针，随后还有微小锁针）实测 **6.606935 mm**。因此不能称原样本已统一满足 10 mm。

1. 采用可观察到的起针顺序：“从入口内部回向端部 → 掉头 → 主路径”。收针采用“到末梢 → 掉头 → 回退 → 结束”。末尾微小来回锁针已由这次的 10 mm 圆弧回线替代，不再叠加。
2. 保留原样本第 6–802 针的主路径顺序，包括 B 的上环和字肚、双 l 连笔、d / g 字肚回走与各交叉点的先后顺序。主路径明确折返点对应原第 **34、63、120、186、225、414、581、613、656** 针；坐标见 `source_stitches.csv`，标注见 `source_analysis.png`。未新增字母间连接，没有跳针。
3. 不是直接照搬原针点。按原针序分段重建三次样条；在明确折返处分段以防曲线抹掉分叉或拖出新笔画。然后按曲率限制弦线偏差，直段约 2.45 mm，转弯自动缩针。与原折线的抽样主路径偏差最大约 0.194 mm（缩放前、不含新回线，属于抽样指标而非连续曲线误差上界）。
4. 新起收回线使用局部偏移和半圆掉头，半径分别选 0.35 / 0.25 mm；不是把所有局部套同一圆。经 DST 格点量化后回测弧长，并校准普通落针宽度到 330.0 mm。

## 检查与边界

已通过：独立位权表解码器与 pyembroidery 的逐命令/逐坐标比较；与写入前整数坐标比较；512 字节文件头、记录数、四向范围、终点、0 换色、单个最终 END、位移可编码性、实际尺寸、回线长度。四项回归测试覆盖正负轴极限位移、缺失 END、错误文件头范围和超界位移。回放页面的滑块和逐针步进已在浏览器核对。

实现参考开源 [pyembroidery](https://github.com/EmbroidePy/pyembroidery)，版本固定在项目 `requirements.lock.txt`。双重回读验证文件结构与坐标一致，不等于 Wilcom 或大豪机器已验证。

**尚未解决：** 内部九处人工尖转仍保留，没有全部改为圆弧；两端局部短针（最短 0.2 mm）及少量回走偏移的实物效果需要检查。没有验证毛线、压脚、速度等工艺参数，也没有在 Wilcom EmbroideryStudio e4.2 导入或大豪 A15-PLUS 试绣。此文件是可检查的试生成版，不能称可直接批量上机的成品。

## 复现与目录迁移

在项目根目录按 docs/developer-guide.md 建立 Python 3.13 环境后执行：

```sh
python scripts/build_pilot.py
python -m unittest discover -s tests -v
python scripts/verify_release.py
```

候选写入 build/bulldogs-font2-330/，不会覆盖此冻结交付目录。代码与依赖清单位于项目根目录；只收到操作方 ZIP 时不需要运行这些开发命令。

目录整理只更新了文档、路径和交付清单，DST 机器文件字节保持不变。原订单识别信息保留在本地私有资料中，公开案例使用 BULL-F2-330-v001 标识。
