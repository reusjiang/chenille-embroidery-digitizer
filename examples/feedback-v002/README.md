# v002 固定对照输入

这 3 组输入取自本地 `feedback/inbox/人工对照反馈50份-僵硬专项/`，样本 ID 保持一致。

- `manual.DST`：人工参考稿，本次作为主路径重建输入，尚无实机合格证明。
- `previous-draft.DST`：本批字体中线生成器的旧候选，仅用于对照。
- 输入哈希、来源反馈哈希及人工主路径针号范围见 `configs/feedback-v002.json`。

固定范围：01-F2-Bulldogs 第 6–802 针，36-F3-Bulldogs 第 7–903 针，43-F3-Cougars 第 7–808 针（1 起始，普通落针）。依据针路回读中的起收折返选取，替换外侧原回线/微锁针，保留内部笔顺。这是本轮数字审查范围，仍待操作方在 Wilcom 中确认。

输入变更会触发哈希校验失败，不能将其他同名文件直接替换后沿用当前针号范围。
